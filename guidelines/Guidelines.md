
# General rules
- Use of flexbox or grid; not avoid absolute positioning 
- Keep code clean by refactoring often
- Keep files small; split helpers and components into their own files

# Design rules
- Base font size: 14px
- Dates: “Jun 10” format
- Bottom toolbar: max 4 items
- No floating action button with bottom toolbar
- Chips: always sets of 3+
- Don’t use dropdowns if only 2 options

## Buttons
- **Primary**: bold, brand color, one per section for the main action
- **Secondary**: outlined, transparent background, for supporting actions
- **Tertiary**: text‑only, least important actions
